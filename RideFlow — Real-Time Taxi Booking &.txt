this is how i want to create my project
1. Authentication & Security Module
Multi-Role User Accounts:
RIDER: Standard customer requesting rides.
DRIVER: Cab driver accepting ride requests.
ADMIN: Platform owner managing fleet and settings.
OTP Verification Service:
SMS / Email OTP verification during signup or password reset (using Twilio / Firebase SMS or simulated dev OTP service).
Stateless JWT Security:
BCrypt password hashing + JWT token authentication for API access.
Driver Verification:
Driver document upload (Driving License, Vehicle Registration RC, Insurance status marked as PENDING_APPROVAL $\rightarrow$ VERIFIED by Admin).
🚗 2. Rider (Customer) Features
Place Autocomplete & Search:
Search pickup & drop-off locations using Google Maps / Mapbox Geocoding API.
Fare & Time Estimator:
Calculates estimated fare before booking based on distance, estimated time, and vehicle tier (Economy, Premium, SUV).
Ride Request & Driver Matching:
Finds the nearest available online driver within a 5km radius using PostgreSQL PostGIS / Redis GeoSpatial.
Live Ride Tracking:
Real-time map view with WebSocket updates showing the driver approaching the pickup point.
Trip Start Verification (Ride OTP):
Generates a 4-digit OTP that the rider gives to the driver to start the trip.
Ratings & Reviews:
Rate driver (1-5 stars) and submit feedback after trip completion.
🚕 3. Driver App Features
Online / Offline Toggle:
Controls availability to receive new ride requests.
Ride Request Popup:
Displays pickup distance and fare with a 15-second Accept / Reject countdown timer.
Trip Lifecycle Management:
ACCEPT_RIDE $\rightarrow$ NAVIGATE_TO_PICKUP $\rightarrow$ INPUT_RIDER_OTP $\rightarrow$ START_TRIP $\rightarrow$ END_TRIP.
Driver Earnings Dashboard:
Daily & weekly earnings summary, total trips completed, and commission breakdown.
🛰️ 4. Real-Time & Geospatial Engine
GPS Location Streaming:
Drivers stream their current latitude/longitude to the Spring Boot backend every 3–5 seconds.
WebSocket Broadcast:
Spring Boot STOMP WebSockets push live driver coordinates to the rider's map view.
PostGIS Spatial Queries:
Queries like ST_DWithin() to instantly locate drivers near a GPS coordinate.
📊 5. Admin Web Dashboard (React)
Live Fleet Map:
Real-time map showing all active drivers, ongoing rides, and pickup hotspots.
Driver Verification Queue:
Approve or reject driver accounts and verify submitted license documents.
Fare & Surge Management:
Set base fare per km, peak hour surge multiplier, and platform commission fee percentage.
Financial & Analytics Reports:
Charts showing total revenue, daily booking volumes, and active driver statistics.
🔔 6. Notification System
Push Notifications (Firebase FCM):
"Your driver has arrived!", "Ride request accepted", or "Trip completed".
In-App Toast Alerts:
Real-time status alerts for riders and drivers.
